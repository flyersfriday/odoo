Flyers Friday Rental App
========================
This module provides rental management features within Odoo for the Flyers Friday business.

Features
========
* Manage rental products, availability, and pricing
* Track rental orders, schedules, and returns
* Generate rental agreements and invoices
* Integrated customer management for rentals
* Dashboard for rental status overview

Configuration
=============
1. Install the module from the Odoo Apps menu.
2. Navigate to Rentals > Configuration to manage settings.
3. Add rental products under Sales > Products with rental properties enabled.
